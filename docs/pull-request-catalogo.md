# Pull Request: aplicación catalogo

Esta rama entrega la aplicación `catalogo` para integrarla en `main`.

- Vista `catalogo:inicio`: catálogo de productos destacados.
- Vista `catalogo:productos`: inventario con stock y estado.
- Templates con herencia desde `templates/base.html`.
- Pruebas de integración para ambas rutas.

Validación ejecutada: `python manage.py check` y `python manage.py test`.
