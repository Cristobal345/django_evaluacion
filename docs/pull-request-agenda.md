# Pull Request: aplicación agenda

Esta rama entrega la aplicación `agenda` para integrarla en `main`.

- Vista `agenda:inicio`: agenda diaria con eventos próximos.
- Vista `agenda:semana`: resumen semanal por día y foco.
- Templates con herencia desde `templates/base.html`.
- Pruebas de integración para ambas rutas.

Validación ejecutada: `python manage.py check` y `python manage.py test`.
